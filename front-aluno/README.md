# Front Aluno

Front-end público do sistema, desenvolvido em **React**, sem necessidade de login.

## O que vai ficar aqui
- Página com a grade de horários
- Página de avisos, com filtro por disciplina
- Listagem dos materiais/slides disponíveis para download
- Consome o Back Acadêmico (grade e avisos) e o Back Materiais (slides)

## Como rodar (preencher conforme o projeto for criado)
```
npm install
npm run dev
```
