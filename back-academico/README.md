# Back Acadêmico

Back-end responsável pelos dados estruturados do sistema, desenvolvido em **Java + Spring Boot**, com banco **PostgreSQL**.

## O que vai ficar aqui
- Entidades: `Disciplina`, `Horario`, `Aviso`
- Endpoints REST para grade de horários e avisos (com filtro por disciplina)
- Conexão e configuração do PostgreSQL

## Como rodar (preencher conforme o projeto for criado)
```
mvn spring-boot:run
```
