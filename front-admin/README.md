# Front Admin

Painel de gestão, desenvolvido em **Vue.js**, acessado por uma rota separada do front do aluno (sem autenticação nesta primeira entrega).

## O que vai ficar aqui
- Formulário para criar/editar avisos
- Formulário para cadastrar/editar horários da grade
- Upload de materiais/slides
- Consome o Back Acadêmico (grade e avisos) e o Back Materiais (upload de slides)

## Como rodar (preencher conforme o projeto for criado)
```
npm install
npm run dev
```
