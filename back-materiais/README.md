# Back Materiais

Back-end responsável pelo armazenamento dos arquivos de slide, desenvolvido em **Python + FastAPI**, com banco **MongoDB (GridFS)**.

## O que vai ficar aqui
- Endpoints de upload e download de slides (PDF)
- Metadados dos arquivos (nome, disciplina, data de upload, referência ao GridFS)
- Conexão e configuração do MongoDB

## Como rodar (preencher conforme o projeto for criado)
```
uvicorn main:app --reload
```
