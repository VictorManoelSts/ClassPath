# Mobile

Aplicativo Android desenvolvido em **Kotlin**, integrando os dois back-ends do sistema.

## O que vai ficar aqui
- Tela de grade de horários e avisos (consumindo o Back Acadêmico)
- Tela de visualização/download de materiais (consumindo o Back Materiais)
- Configuração de requisições HTTP (ex: Retrofit) para os dois backs

## Como rodar
Abrir a pasta no Android Studio e rodar em um emulador ou dispositivo físico.
