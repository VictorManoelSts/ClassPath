Documentação Completa do Sistema

ESPECIFICAÇÕES TÉCNICAS E ARQUITETURA

Protótipo funcional da plataforma acadêmica desenvolvido para a turma da faculdade, unificando avisos, horários, disciplinas, professores e materiais didáticos com entrega prevista para 16 de setembro.

Visão Geral do Projeto

O Portal da Turma é uma solução centralizada criada para otimizar a comunicação e o acesso a conteúdos acadêmicos. O sistema resolve problemas de dispersão de avisos e documentos, permitindo que os estudantes consultem grades horárias e materiais em PDF de forma organizada e com filtros por disciplina.

Micro Front-end do Aluno

React + TypeScript

Interface web moderna e responsiva voltada para os estudantes. Permite a consulta rápida de avisos recentes, visualização da grade horária completa das disciplinas, verificação de dados dos professores e descarregamento direto dos materiais didáticos disponibilizados.

Micro Front-end Administrativo

Vue + JavaScript

Painel web independente dedicado à gestão de conteúdos. É através desta aplicação que os administradores conseguem cadastrar novos avisos acadêmicos, atualizar grades e enviar os ficheiros PDF das aulas para o sistema.

Aplicativo Mobile Android

Kotlin

Aplicação nativa desenvolvida para dispositivos móveis. Atua como o terceiro cliente do ecossistema, consumindo diretamente as APIs dos back-ends para garantir que os alunos tenham acesso a todas as informações na palma da mão.

Back-end Acadêmico (API REST)

Java + Spring Boot

Servidor principal responsável por gerir a lógica de negócios e todos os dados estruturados do sistema. Processa as requisições relacionadas a disciplinas, horários, professores e avisos acadêmicos com total segurança e alta performance.

Back-end de Materiais (API REST)

Python + FastAPI

Servidor especializado e assíncrono focado estritamente no tratamento de ficheiros. Lida com o recebimento de uploads, listagem, pesquisa e a disponibilização otimizada dos slides e materiais de aula em PDF.

Camada de Armazenamento e Bases de Dados

PostgreSQL e MongoDB / GridFS

A arquitetura de dados separa rigorosamente as responsabilidades: o PostgreSQL armazena com integridade relacional todos os dados estruturados do sistema pelo back-end Java. Em paralelo, o MongoDB (com GridFS) é utilizado pelo back-end Python para gerir de forma altamente eficiente o armazenamento binário de grandes ficheiros e PDFs.
